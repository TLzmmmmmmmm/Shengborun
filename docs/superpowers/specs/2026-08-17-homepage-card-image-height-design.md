# 首页卡片图片高度调整设计

## 目标

在不改变首页卡片宽度的前提下，统一缩短“产品中心”和“行业解决方案”两个模块的卡片图片区域，使卡片整体更加紧凑。

## 设计

- 两个模块继续复用现有 `.image-card` 与 `.image-card img` 样式，不新增组件或模块专属规则。
- 将图片区域的宽高比从 `16 / 10` 调整为 `2 / 1`，在相同宽度下将高度缩短约 20%。
- 桌面端、平板端和移动端使用同一比例，保持跨屏幕的一致性。
- 保留 `width: 100%` 和 `object-fit: cover`，并显式设置 `height: auto` 覆盖图片标签的固定高度属性，因此图片会按 `2:1` 填满容器，必要时从上下方向裁切。
- 不调整卡片宽度、网格列数、正文区域高度、间距、圆角、阴影或交互效果。

## 影响范围

仅修改 `src/pages/index.astro` 中 `.image-card img` 的高度与宽高比声明。保留该文件当前未提交的首页修改，不触碰图片资源或首页数据。

## 验证

- 运行 Astro 静态检查与构建，确认样式语法和页面生成正常。
- 检查首页产品与解决方案卡片都应用 `2:1` 图片比例。
- 检查移动端仍为单列布局，图片宽度填满卡片且没有拉伸变形。
