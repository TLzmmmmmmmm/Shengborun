# 盛博润网站品牌配色规范

## 设计定位

网站采用稳重、可靠的通信企业形象。整体视觉参考苹果官网的克制风格，以黑、白、灰构成页面主体，通过充足留白和明暗区块建立层次。Logo 中的青绿色作为品牌识别色，主要用于按钮、链接和少量状态提示，不作为大面积页面背景。

## 品牌颜色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 品牌青绿 | `#00B7B5` | 主要按钮、少量品牌识别、当前状态 |
| Logo 石墨 | `#202B33` | Logo 主体；必要时用于高强调文字 |
| 青绿深色 | `#007C7B` | 文字链接、描边按钮、主按钮按下状态 |
| 青绿浅底 | `#E5F8F7` | 选中项、提示区、关键功能标签背景 |

## 中性色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 主文字／深色区 | `#1D1D1F` | 标题、正文主色、页脚和少量深色区块 |
| 纯白背景 | `#FFFFFF` | 页面主要背景 |
| 浅灰背景 | `#F5F5F7` | 产品、解决方案和技术支持区块的交替背景 |
| 分隔灰 | `#E8E8ED` | 区块分隔、弱边界 |
| 边框灰 | `#D2D2D7` | 卡片、表格和输入区域边框 |
| 次级文字 | `#6E6E73` | 摘要、说明、辅助信息 |

## 按钮规范

### 主要按钮

- 默认背景：`#00B7B5`
- 默认文字：`#202B33`
- 悬停背景：`#00A3A1`
- 悬停文字：`#202B33`
- 按下背景：`#007C7B`
- 按下文字：`#FFFFFF`
- 不可用背景：`#B8DAD9`
- 不可用文字：`#627574`

青绿色与白色的对比度不足，因此默认主按钮不使用白字。深色石墨文字可以保持清晰度，也能与 Logo 主体形成呼应。

### 次要按钮

- 背景使用白色或透明色。
- 边框和文字使用 `#007C7B`。
- 同一内容区中，主要按钮只能有一个；其余操作使用次要按钮或文字链接。

## 页面背景规则

- 白色 `#FFFFFF` 是全站主要背景。
- 浅灰色 `#F5F5F7` 用于交替划分内容模块，避免长页面连续纯白。
- 深色 `#1D1D1F` 仅用于页脚、重点服务区或少量品牌展示区，不连续覆盖多个区块。
- 青绿色不用于大面积背景、长篇正文或大段标题。
- 产品图片和系统结构图优先放在白色或浅灰背景上，避免与品牌色竞争。

## 文字、链接与标签

- 一级标题、二级标题和正文使用 `#1D1D1F`。
- 摘要、说明和辅助信息使用 `#6E6E73`。
- 正文链接使用 `#007C7B`，不能直接使用较亮的 `#00B7B5`。
- 产品关键功能标签使用 `#E5F8F7` 背景与 `#007C7B` 文字。
- 青绿色必须与文字、图标或形状共同表达状态，不能让含义只依赖颜色。

## 导航命名

顶部导航中的解决方案栏目统一命名为“解决方案”，对应路径保持为 `/solutions`。

## 使用比例建议

- 黑、白、灰中性色约占页面视觉面积的 90%–95%。
- 品牌青绿色及其状态色约占 5%–10%。
- 青绿色集中出现在需要用户采取行动的位置，保持识别度和稀缺性。
